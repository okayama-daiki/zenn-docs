## Too Long; Didn't Learn?

- Zed (Vim Keybidings) の Normal Mode ではキー入力が IME に渡されない
- なので、Insert Mode で `Ctrl + [` によって IME が ON のまま Normal Mode に移動したとしても
- **IME が ON の状態のまま** Normal Mode で操作ができ、同じくそのまま Insert Mode に入れます

## はじめに：簡単な自己紹介と周囲の課題について

ターミナルで vim をバリバリ使うというよりは、VSCode みたいな統合開発環境や、Google Colab や Overleaf (LaTeX のクラウドエディタ)で vim キーバーインディングが選択肢としてあれば使う程度の　vim ユーザです。

これまで日本語の文書を編集する流れはこのような感じでした。

```txt
(normal mode)
i
↓　(insert mode)
IME ON
↓　(insert mode / 日本語)
編集
↓
IME OFF
↓ (insert mode / alphabet)
jj
↓
(normal mode)
```

毎度モードの切り替えのタイミングで IME の ON/OFF を切り替えないといけないというのは、モードの切り替えを細かく行おうとすればするほど手間なんですよね。切り忘れると、ご経験のある方はお馴染みかもしれませんが、`っj` みたいになって insert mode　から抜けられずとてもストレスです。そして何より、IME の状態を覚えておくなんてことは私にとっては認知負荷が高すぎました。

もう 1 点だけ `jj` を `<Esc>` に割り当てることの問題はタイムアウト...
